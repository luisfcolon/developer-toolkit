# VS Code Extensions

| Extension | Description |
|-----------|-------------|
| [anthropic.claude-code](vscode:extension/anthropic.claude-code) | Claude Code AI assistant by Anthropic — chat, code generation, and agentic tasks directly in VS Code |
| [esbenp.prettier-vscode](vscode:extension/esbenp.prettier-vscode) | Prettier — opinionated code formatter supporting JS, TS, CSS, HTML, JSON, Markdown, and more |
| [hashicorp.terraform](vscode:extension/hashicorp.terraform) | HashiCorp Terraform — syntax highlighting, IntelliSense, and formatting for .tf files |
| [mohsen1.prettify-json](vscode:extension/mohsen1.prettify-json) | Prettify JSON — formats raw or minified JSON into readable, indented output |
| [ms-python.black-formatter](vscode:extension/ms-python.black-formatter) | Black — opinionated Python code formatter, enforces consistent style automatically on save |
| [ms-python.debugpy](vscode:extension/ms-python.debugpy) | Python Debugger — debugpy-based debugger for stepping through Python code, breakpoints, and watch expressions |
| [ms-python.python](vscode:extension/ms-python.python) | Python — core language support including linting, IntelliSense, environments, and test discovery |
| [ms-python.vscode-pylance](vscode:extension/ms-python.vscode-pylance) | Pylance — fast Python language server with type checking, auto-imports, and rich IntelliSense powered by Pyright |
| [ms-python.vscode-python-envs](vscode:extension/ms-python.vscode-python-envs) | Python Environments — manage virtual environments, conda envs, and interpreters from within VS Code |
| [openai.chatgpt](vscode:extension/openai.chatgpt) | ChatGPT — OpenAI's extension for code explanations, generation, and chat inside VS Code |
| [opentofu.vscode-opentofu](vscode:extension/opentofu.vscode-opentofu) | OpenTofu — syntax highlighting, validation, and IntelliSense for OpenTofu (open-source Terraform fork) |
