## Visual Studio Code

### Settings

Editor preferences and configuration for VS Code. — [vscode/settings.json](vscode/settings.json)

To apply these settings, open your VS Code `settings.json` directly:

1. Open the Command Palette (`Cmd+Shift+P`)
2. Type and select **Preferences: Open User Settings (JSON)**
3. Copy the contents of [vscode/settings.json](vscode/settings.json) into the file and save
